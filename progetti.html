01
Completato

Vivaio — Web Application

Sito full-stack per gestire un vivaio online: login/registrazione con sessioni PHP, area admin per il catalogo piante, carrello e ordini su MySQL. L'ho fatto responsive perché ormai tutti guardano dal telefono.

Password hashate, ruoli admin/cliente, CRUD sul catalogo con immagini, filtri per categoria. Ho cercato di tenere il codice ordinato tipo MVC — quando torni sul progetto dopo mesi, ti ringrazi.

HTML / CSS JavaScript PHP 8 MySQL MVC Responsive

02
Completato

Robotica ABB — Pick & Place

Cella robotica con IRB 1200: il robot prende lettere sparate a caso sui riquadri di carico e le ricompone nell'ordine giusto del cognome dell'operatore, dall'altra parte della cella. Sembra un gioco, ma dietro c'è tutta la logica di un processo industriale.

RAPID modulare, gestione errori, traiettorie ottimizzate e coordinamento con PLC virtuale. Ho documentato layout e tempi di ciclo — serve anche a capire dove si può migliorare.

ABB RAPID RobotStudio Automazione Pick & Place PLC
04
In sviluppo

Lost&Found scolastico — Python

App desktop in Python + Tkinter per l'ufficio oggetti smarriti della scuola. Registri cosa trovi, chi segnala cosa, filtri per categoria e stato, backup su JSON. L'idea è semplice ma utile — quante penne perse ci sono in un anno?

Uso OOP per tenere il codice leggibile, ricerca avanzata e (in futuro) export PDF con ReportLab. Ancora in corso, ma la base gira.

Python 3 Tkinter OOP JSON ReportLab
